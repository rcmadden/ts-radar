Local Admin

Update the installed Tableau Server version and refresh the data used by both dashboards.

Start the local admin server with python3 scripts/serve.py --port 8765, then open localhost:8765/admin.html.

Installed version

Target is the newest patch in the current series, or the newest patch of the next series when fully patched. Stable is the newest series at patch .4 or later. Latest follows the Server release catalog, including releases with no issue fixes.

Refresh source data

Fetch Server releases and resolved issues, Salesforce known issues, and NVD security advisories. Existing classifications are preserved. Each source is validated before its data is replaced; failed sources keep their last successful data.

Salesforce access token (only if automatic retrieval fails)

Copy the Coveo access token from a search request on Salesforce Help. It is used for this refresh and is never saved.

Admin access token (only when the server sets ADMIN_TOKEN)

Required when the admin server runs with an admin token, e.g. on hosted deployments. It is kept in this browser session only.

Without an admin token the server accepts admin requests only from this computer. Hosted deployments (e.g. DSMLP) should set ADMIN_TOKEN so only token holders can refresh.
